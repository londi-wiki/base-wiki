Jeder Punkt ist eine Seite, jede Linie eine Verbindung. Graue Linien zeigen die
Ordnerstruktur, grüne Linien echte Querverweise zwischen Beiträgen.

{{< wiki-graph >}}

Über die Farben lassen sich die Bereiche filtern, die Suche hebt einzelne Seiten
hervor. Ein Klick auf einen Punkt öffnet die zugehörige Seite.
